# Розпаковка

Анкета на 133 питання для СММ-спеціалістки: з відповідей збирається сторінка (шапка, актуальні, рубрики, тон, візуал).
Статичний сайт, працює на GitHub Pages: https://yakovina.github.io/rozpakovka/

- `index.html` — анкета (питання, стилі, скрипт в одному файлі), Material Design.
- `questions.json` — питання окремо: блок, рубрика, доказ, «для чого» — для обробки відповідей.

Що вміє: питання по одному з підказкою «Доказ»; диктування голосом (Chrome, Safari) і мікрофон на клавіатурі телефону;
відповіді зберігаються в браузері; в кінці — «Скопіювати відповіді» і файл JSON.

## Кейси — `keisy/`

Друга сторінка в тому ж стилі: https://yakovina.github.io/rozpakovka/keisy/
Один клієнт — один кейс, 14 питань. На першій сторінці — нік (той самий, що в анкеті) і список своїх кейсів з таблиці:
можна відкрити будь-який і дописати. Відповіді лягають у ту ж таблицю, аркуш «Кейси» (один кейс — один рядок).

- `keisy/index.html` — сторінка (питання, стилі, скрипт в одному файлі).
- `keisy/questions.json` — питання окремо.
- `Code.gs` — скрипт таблиці (Apps Script), спільний для анкети і кейсів: поле `sheet` каже, в який аркуш писати.
