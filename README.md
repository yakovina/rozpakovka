# Розпаковка особистості та експертності

Анкета на 88 питань для СММ-спеціалістки: з неї збирається сторінка (шапка, актуальні, рубрики, тон, візуал).
Працює як статичний сайт — достатньо GitHub Pages.

- `index.html` — вся анкета в одному файлі (питання, стилі, скрипт).
- `questions.json` — ті самі питання окремо, для обробки відповідей.

## Що вміє
- Питання по одному, з блоком «Доказ» під кожним — що прикласти або перевірити, щоб не набрехати собі.
- «Надиктувати» — розпізнавання мови в браузері (українська), Chrome і Safari. На телефоні працює і мікрофон на клавіатурі.
- Фільтр за блоком, за «для чого» (шапка, рубрики, тон…), за статусом; сортування.
- Відповіді зберігаються в браузері самі (localStorage).
- «Перевірка» — 9 пар відповідей на розрив між «як кажу» і «як є».
- «Експорт» — текст для чату, JSON, CSV; імпорт JSON, щоб продовжити на іншому пристрої.

## Як опублікувати
Settings → Pages → Source: Deploy from a branch → `main`, папка `/ (root)`. Через хвилину сторінка буде на `https://<нік>.github.io/<репозиторій>/`.
